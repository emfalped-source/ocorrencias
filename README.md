# Ocorrências EMFAL

Registro de ocorrências da coordenação pedagógica da Escola Municipal Francisca Alves (EMFAL).

- Entrada com o mesmo usuário e senha do Corretor EMFAL; só o perfil coordenação tem acesso.
- Turmas e estudantes vêm do Corretor EMFAL.
- Os registros ficam numa planilha do Google Drive da coordenação, nunca neste repositório.

Endereço: https://emfalped-source.github.io/ocorrencias/
